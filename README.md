# 🏛️ DocGen Omnichannel Platform

**Детерминированная омниканальная платформа генерации и сборки юридических договоров РФ** (Zero-LLM Runtime / ГОСТ Р 7.0.97-2016).

---

## 🌟 Ключевые возможности

* **100% Алгоритмическая детерминированность (Zero-LLM):** Исключены любые галлюцинации языковых моделей. Текст договора собирается из выверенных правовых блоков Гражданского кодекса РФ.
* **Математическая валидация реквизитов (ФНС и ЦБ РФ):**
  * Проверка контрольных сумм **ИНН** (10 цифр для ЮЛ и 12 цифр для ИП/ФЛ);
  * Проверка **КПП** и **ОГРН/ОГРНИП** (13 и 15 знаков);
  * Проверка **БИК** и связки **БИК + 20-значный расчетный/корреспондентский счет** по алгоритмам Банка России.
* **Суммы прописью и НДС:** Автоматическое склонение числительных, рублей и копеек с юридически точной расшифровкой НДС (20%, 10%, без НДС / УСН).
* **Оформление Word строго по ГОСТ Р 7.0.97-2016:** Поля (25/15/20/20 мм), шрифт Liberation Serif, абзацный отступ 1.25 см, межстрочный интервал 1.15, защита от висячих строк (`widowControl`), запрет разрыва строк таблиц (`cantSplit`), повтор шапки таблиц (`tblHeader`) и двухколоночный блок подписей.
* **Векторная компиляция PDF (Typst):** Мгновенная сборка типографского качества без тяжелых зависимостей.
* **Омниканальный доступ (5 каналов):**
  1. **Web UI** (React 19 + Vite + Glassmorphism UX);
  2. **REST API** (FastAPI + Swagger / OpenAPI);
  3. **Telegram-бот** (Aiogram 3 + FSM-визард);
  4. **Desktop GUI** (Tkinter + автономная сборка PyInstaller в `.exe`);
  5. **MCP Servers** (Model Context Protocol).

## 📑 Поддерживаемые виды договоров

| Тип | Наименование | Законодательная база | Особенности |
| :--- | :--- | :--- | :--- |
| `supply` | **Договор поставки товаров** | ГК РФ гл. 30 §3 | Табличная спецификация, адреса складов, условия приемки |
| `services` | **Договор возмездного оказания услуг** | ГК РФ гл. 39 | Перечень услуг, передача РИД, сроки рассмотрения Акта |
| `work` | **Договор подряда** | ГК РФ гл. 37 | Календарный план, этапы КС-2, гарантийные обязательства |
| `nda` | **Соглашение о конфиденциальности** | 98-ФЗ «О коммерческой тайне» | Перечень сведений, сроки охраны, фиксированные штрафы |

## 🚀 Быстрый запуск

### 1. Запуск через Docker Compose (Рекомендуемый способ)

```bash
# Клонируйте репозиторий и создайте .env файл
cp .env.example .env

# Соберите и запустите сервисы (Web UI, REST API, Bot)
docker compose up --build -d
```

* **Web UI (Фронтенд):** [http://localhost](http://localhost)
* **REST API Swagger:** [http://localhost:8000/docs](http://localhost:8000/docs)
* **Health Check:** [http://localhost:8000/api/health](http://localhost:8000/api/health)

---

### 2. Локальный запуск (Разработка)

#### А. Backend (FastAPI REST API):
```bash
# Активация виртуального окружения
source .venv/bin/activate

# Запуск сервера
uvicorn adapters.api.server:app --reload --port 8000
```

#### Б. Frontend (React 19 Web UI):
```bash
cd adapters/web_ui
npm install
npm run dev
```

#### В. Telegram-бот:
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
python -m adapters.telegram_bot.bot
```

#### Г. Десктопное приложение:
```bash
python -m adapters.desktop_windows.app
```

Для сборки автономного `.exe` исполняемого файла:
```bash
python adapters/desktop_windows/build_windows.py
```

## 📡 Основные API Эндпоинты

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/contracts/types` | Список доступных видов договоров с метаданными |
| `GET` | `/api/contracts/sample/{type}` | Эталонные заполненные данные договора |
| `POST` | `/api/contracts/validate-party` | Валидация реквизитов (ИНН, БИК, расчетный счет) |
| `GET` | `/api/contracts/suggest/{inn}` | Автоподтягивание данных организации по ИНН |
| `POST` | `/api/contracts/calculate` | Расчет сумм, НДС и генерация суммы прописью |
| `POST` | `/api/contracts/generate/docx` | Генерация и скачивание документа Word по ГОСТ |
| `POST` | `/api/contracts/generate/pdf` | Компиляция и скачивание векторного PDF (Typst) |
| `POST` | `/api/drafts` | Сохранение черновика |
| `GET` | `/api/drafts` | Получение списка всех сохраненных черновиков |
| `DELETE`| `/api/drafts/{id}` | Удаление черновика |

## 🛡️ Безопасность и приватность

Платформа спроектирована по принципу **Privacy-First**:
* Генерация документов и проверка математических контрольных сумм выполняются **на 100% локально**;
* Никакие юридические реквизиты, суммы или персональные данные сторон не отправляются во внешние нейросетевые API.
